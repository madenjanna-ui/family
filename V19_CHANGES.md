# Family v19

## Главный экран
- Главная страница показывает только уже начатые разговоры.
- Новый серверный endpoint `/api/chats` отдаёт сводку чатов без загрузки полной истории каждого диалога.
- Сортировка — по последнему сообщению.
- Группа/личный чат без сообщений не появляется на главной.

## Быстрые действия
- Новое сообщение
- Создать группу
- Голосовой звонок
- Видеозвонок
- Фото
- Видео
- Голосовое сообщение

Создание группы убрано с главной и находится только в быстрых действиях.

## Звонки
- Голосовой и видеозвонок разделены в интерфейсе.
- Входящий вызов отображается поверх любого экрана.
- ICE-кандидаты ставятся в очередь до появления remote description.
- После установки соединения отображается «На связи».
- Сервер сохраняет pending call и отправляет push, если получатель временно без WebSocket.

## Чаты и уведомления
- Если открыт конкретный чат, push для этого же чата подавляется сервером.
- Быстрая загрузка главной страницы не требует загрузки истории каждого пользователя.
- Исправлена вставка отправленного сообщения в групповой чат.
- Исправлена ошибка со ссылкой на несуществующую переменную `scope` в `appendSentMessage`.

## Медиа
- Быстрые действия для фото/видео сначала открывают выбранный личный чат, затем запускают выбор файла.
- Фото/видео продолжают использовать существующий API.
- Голосовые сообщения остаются в локальном MediaVault после доставки.

## Service Worker
- Убрана проблемная схема кэширования, приводившая к `Response body is already used`.
- Cache version обновлена до v19.

## Данные
- Код v19 не содержит рабочий `server/data/family.json`.
- Railway Persistent Volume `/app/data` не должен заменяться файлами из архива.
