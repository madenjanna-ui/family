# Family v20

Собрано поверх актуального ZIP пользователя.

- Главная: только начатые чаты через `/api/chats`.
- Группы: создание любым пользователем, текст/медиа/голосовые, unread.
- Лимит пользователей: по умолчанию 10, администратор может менять до 100.
- Новые пользователи не добавляются автоматически в существующий чат «Семья».
- WebSocket: активный чат используется для подавления push; звонки могут временно храниться сервером до подключения получателя.
- ICE queue и входящий вызов поверх любого экрана сохранены.
- Service Worker cache поднят до v20.
- `server/data/family.json` и `server/data/vapid.json` в архив не включаются.
